Thimo cia Gikuyu

A growing collection of Gikuyu proverbs, gathered one contribution at a time. Add a thimo and help keep this living heritage available for the next generation.

Share a proverb

The project includes add_proverb.py, a small command-line tool for collecting proverbs. Each entry is appended to thimo.csv, creating a simple, growing record of community knowledge.

Run the program, type your proverb, and press Enter. When you are finished, submit an empty line to leave the contribution prompt.

How it works

  1. Open a terminal in the project directory.
  2. Run python add_proverb.py.
  3. Enter a Gikuyu proverb when prompted.
  4. Press Enter on an empty prompt to finish.
